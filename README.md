# Requirements
- kitty
- i3
- i3status
- picom
- feh
# Optional stuff
- fastfetch
- neovim

# Disclaimer
If you're using Systemd, remove the lines:
```
exec --no-startup-id pipewire
exec --no-startup-id wireplumber
exec --no-startup-id pipewire-pulse
```
from the config or audio may be broken.
